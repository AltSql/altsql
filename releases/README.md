# Releases

From 0.4.0 on, releases are published on the
[GitHub release page](https://github.com/AltSql/altsql/releases), with
binaries for Linux and macOS; [RELEASING.md](../RELEASING.md) says how. This
folder keeps the earlier releases as they were: each has a folder here with
its notes, and its binaries where there are any.

| Release | Date | What it holds |
|---|---|---|
| [v0.4.0](https://github.com/AltSql/altsql/releases/tag/v0.4.0) | 8 October 2026 | AltSql Core and AltSql DB 0.4.0; both shells for Linux x86-64 and ARM64 and macOS, on the release page |
| [v0.3.0-alpha](v0.3.0-alpha/) | 5 October 2026 | AltSql DB 0.3.0-alpha (statement savepoints, secondary indexes) and AltSql Core 0.1.0-alpha; both shells for Linux x86-64 ([notes](v0.3.0-alpha/NOTES.md)) |
| [v0.2.0-alpha](v0.2.0-alpha/) | 5 October 2026 | AltSql DB 0.2.0-alpha and AltSql Core 0.1.0-alpha; the `altsql` and `altsql-db` shells for Linux x86-64 ([notes](v0.2.0-alpha/NOTES.md)) |
| v0.1.0-alpha | 2 October 2026 | The first public release, source only: [release page](https://github.com/AltSql/altsql/releases/tag/v0.1.0-alpha) |

The source of a release is the commit that added its folder; [CHANGELOG.md](../CHANGELOG.md) lists
what changed. Everything here is under the Apache License 2.0. Copyright 2026 AltSql.com.
